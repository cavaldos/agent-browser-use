Agent Browser Use

Let AI coding agents drive a real browser over MCP, while you watch every step live in a web page and take over at any time.

GitHub Releases

Quick start

curl -fsSL https://raw.githubusercontent.com/cavaldos/agent-browser-use/main/scripts/install.sh | sh
agent-browser-use
# Viewer: http://localhost:3000  |  MCP: http://localhost:3000/mcp

Features

  • Playwright-style MCP tools with element refs (browser_snapshot).
  • Live viewer: cursor, captions, step log, take-over / block agent.
  • Pick an element and share its code with your coding agent.
  • Record and replay flows (with inputs), export/import.
  • Persistent logins via profile folder; no Docker required.
